# Question bank

In the repo, this folder contains only the **example question** [`example-hello`](example-hello).
Real assessment/practice questions contain reference solutions, so manage them separately (e.g. in another private repo),
then put them into the system by uploading a zip in the admin pages or with `deploy/push-questions.sh <question-bank-dir>`.

- Question package format and how to write questions: [docs/en/QUESTIONS.md](../docs/en/QUESTIONS.md)
- For local development you can put questions here (`.gitignore` excludes every folder except the example question)
