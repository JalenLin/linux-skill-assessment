這是一題**多容器範例題**：兩個網路之間有一台路由器。

```
pc1 ──(lan 192.168.10.0/24)── r1 ──(dmz 172.16.0.0/24)── web
```

| 機器 | eth1 | eth2 |
|---|---|---|
| `pc1` | 192.168.10.10（lan） | |
| `r1` | 192.168.10.1（lan） | 172.16.0.1（dmz） |
| `web` | 172.16.0.10（dmz） | |

用終端機上方的分頁切換機器。**不要改 eth0**，那是管理網路。

在 `pc1` 上 `curl http://172.16.0.10/` 應該看到 `Hello DMZ`，但現在連不上。請修好，並且：

1. `r1` 要在兩個網路之間轉送封包，重開機後也一樣
2. `pc1` 可以開啟 `web` 的網頁，而且 `web` 的防火牆要維持啟用：開放需要的就好，不要整個關掉

按「檢查作答」時會**重開 r1**，並從 LAN 上另一台用戶端測試網頁。

提示：`ip route`、`sysctl`、`nft list ruleset`、`tcpdump`（在 r1 上）。帳號 `user` 可以使用 `sudo`。
