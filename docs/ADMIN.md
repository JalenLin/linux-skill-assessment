## 基本觀念

| 名詞 | 意思 |
|---|---|
| **題目** | 一個題目包（見 [QUESTIONS.md](QUESTIONS.md)），建置後成為 PVE 上的一個**範本** |
| **題組** | 一次測驗或一次練習：選哪些題目、配分、開放時間、計分方式。分成「測驗」和「練習」兩種 |
| **實例** | 某位作答者在某個題組某一題的環境（從範本 linked clone）。**同一題放在不同題組，是不同的環境、不同的成績** |
| **檢查** | 作答者按「檢查作答」，或測驗結束後的「最終校驗」，執行該題的 check.yml 評分 |

## 帳號

作答者帳號是**預先發出**的：管理者產生帳號、列印紙條發給作答者，作答者第一次登入時輸入編號綁定。

- **批次產生帳號**：前綴 + 數量 + 起始編號，例如 `p001`～`p060`，密碼隨機 8 碼
- **列印帳密紙條**：一張紙印多組，剪開發給作答者
- **匯入 CSV**：`username,password[,participant_code][,note]`；密碼留空會隨機產生；有填編號就直接綁定
- **匯出 CSV**：含初始密碼與綁定狀態
- 每列的操作：**解除綁定**（作答者綁錯編號時）、**重設密碼**、**刪除**

> 帳號綁的是編號，成績、出席都依編號整理。建議多產生幾個備用帳號。

## 題庫

- **上傳 zip**：一個 zip 一題（zip 裡是題目資料夾）。同名題目會被取代
- **建置範本＋自我測試**：從 base 範本建立這題的範本（1~5 分鐘），然後自動測試：
  未作答應為 0 分、套用 `solution.yml` 應為滿分，兩者都對才顯示「自我測試通過」
- 題目改了 `setup.yml` / `files/` 會標示**需要重新建置**；只改敘述、check.yml、翻譯不用重建
- 題目頁可看建置紀錄、預覽題目、匯出 zip、刪除
- 題庫頁會列出每題被哪些題組使用

> 重新建置範本**不會**影響已經發給作答者的實例（它們是從舊範本 clone 的）。
> 要讓作答者用新版，必須刪除該題組的實例（作答者下次開題會重新建立）。

## 題組（測驗／練習）

「題組（測驗/練習）」頁可新增題組。新增時可以**複製既有題組的題目與配分**。新題組預設不公開。

### 題組設定

| 設定 | 說明 |
|---|---|
| 類型 | **練習**：不計入測驗，時間可不限。**測驗**：要設定時間，結束後自動停止環境，可執行最終校驗 |
| 開始／結束時間 | 練習可留空（開始留空＝立即開放，結束留空＝一直開放）；測驗兩個都要填 |
| 作答者可見 | 取消勾選＝草稿，作答者看不到 |
| 題組公告 | 作答者在題目列表上方看到 |
| 計分方式 | **取每題最高分** / **取每題最後一次檢查** / **只採計結束後「最終校驗」**（單題限時的題目一律取作答時間內最高分） |
| 檢查冷卻時間 | 兩次檢查之間至少間隔幾秒 |
| 作答者可看到每個檢查項目是否通過 | 關閉時作答者只看到總分；練習建議開啟，測驗看需求 |
| 禁止在終端機貼上 | Ctrl+V、右鍵、拖放都會被擋，伺服器端也會丟棄並記錄 |

### 每題設定

在題組頁下方的題目表：勾選「納入」並儲存，該題就出現在這個題組。

| 欄位 | 說明 |
|---|---|
| 配分 | 每個檢查項目的分數（預設來自 question.yaml） |
| 限時（分） | 0 = 不限時（題組開放時間內自由作答）。限時題目開始作答後倒數，時間到環境會重置 |
| 次數 | 限時題目可以開始作答的次數，0 = 不限 |

### 測驗與練習的互動

**任何一場測驗進行中時，所有練習題組自動暫停**：練習環境停止、終端機斷線、作答者被導向測驗。測驗結束後恢復。

## 練習與出席

每次上課（或每次訓練）開一個練習題組，就同時有**練習成績**與**出席**：

1. 新增練習題組（例如「第 5 週練習」），**設定開始／結束時間為上課時段**
2. 作答者在時間內進入題組、開題、連終端機或按檢查，就記為**出席**（只登入不算）
3. 結束時間到了作答者不能再檢查，成績就固定了
4. 「**練習總表**」列出每位作答者每次練習的出席與得分，可設定「晚到超過 N 分鐘」標示，可匯出 CSV

成績總覽的出席欄會顯示 IP 數量；同一人有多個 IP，可能是換電腦或代登。作答者頁的「活動紀錄」有詳細時間與 IP。

> 練習結束、成績確定後，到題組頁按「**刪除此題組所有實例**」釋放空間（成績紀錄保留）。
> 系統能容納的實例數有限，見 [OPERATIONS.md](OPERATIONS.md#儲存空間lvm上限)。

## 測驗流程檢查表

**測驗前一週**

- [ ] 所有測驗題目都「自我測試通過」
- [ ] 建立測驗題組：題目、配分、時間、計分方式、是否禁止貼上
- [ ] 用測試帳號完整做一次（開題、作答、檢查、看成績）
- [ ] lsa-web 改固定 IP、改掉後台密碼（見 [INSTALL.md](INSTALL.md#7-測驗前的網路設定)）
- [ ] 產生並列印作答者帳號

**測驗前一天**

- [ ] 刪除不再需要的練習題組實例（騰出空間）
- [ ] 確認作答者都已綁定編號（或準備現場綁定）
- [ ] 測驗題組頁按「**預先建立實例**」：為已綁定編號的帳號建立所有題目的環境。
      **約 8 秒一個，60 人 × 12 題約 1.5 小時**，請提早做。測驗開始時作答者只需要啟動
- [ ] 系統設定的「每位作答者同時運作的環境數上限」建議維持 **1**
- [ ] 測驗公告寫上：一次只能開一題，切換題目時前一題會暫停（檔案保留）；手動啟動的服務記得 `enable`

**測驗中**

- 「成績總覽」選測驗題組：即時看每人每題分數、出席、運作中的環境
- 「**延長 10 分鐘**」：整場延長
- 作答者頁：看該作答者的實例、限時作答紀錄（可立即結束、重設次數）、檢查紀錄、終端機紀錄
- 作答者環境壞了：請作答者自己按「重置環境」（會回到初始狀態），或在後台處理

**測驗結束後**

- [ ] 時間到系統自動停止測驗環境、終端機斷線
- [ ] 計分方式為「最終校驗」時，按「**最終校驗（全部）**」：依測驗結束時的環境狀態重新評分
      （只檢查有作答的實例；165 個約 13 分鐘）
- [ ] 「匯出成績 CSV」
- [ ] 成績確定後刪除測驗題組實例

## 成績總覽與作答者頁

- **成績總覽**：上方切換題組，顯示成績矩陣（每人每題）、總分、出席、運作中的環境；可匯出 CSV
- **作答者頁**（點編號進入）：
  - 實例：各題組各題的環境與狀態
  - 限時作答紀錄：可「立即結束」（並重置環境）、「重設此題次數」
  - 檢查紀錄：每次檢查的時間、得分、訊息，點進去可看各檢查項目與 Ansible 輸出
  - 終端機紀錄：每次連上終端機一筆，列出開始時間、題組、題目、長度、輸入次數、貼上被擋次數
    - **重播**：用 asciinema-player 像影片一樣播放，可暫停、調速度、拖時間軸；閒置超過 2 秒的片段自動縮短
    - 右邊是**輸入列表**（每一行指令、方向鍵、⌫ 等按鍵與時刻），點一下跳到那個時間；被擋下的貼上會標紅
    - 「輸入文字」「畫面文字」可以純文字檢視（方便搜尋、複製）；「.cast」下載原始檔，可用 `asciinema play` 在本機播放
    - 刪除帳號或題組時，相關紀錄會一併刪除
  - 活動紀錄：登入、進入題組、開題、連終端機（出席依據）

## 實例（作答者環境）管理

「實例」頁列出所有作答者環境，可個別停止、啟動、刪除，或全部停止。

- 作答者閒置（沒有連終端機）超過設定時間會自動暫停，內容保留
- 題組結束後，該題組的環境自動停止
- 暫停一律是**正常關機**（不是斷電），作答者的檔案不會遺失

## 系統設定

| 設定 | 說明 |
|---|---|
| 網站標題、首頁公告 | 作答者登入後所有頁面上方看到公告 |
| 每位作答者同時運作的環境數上限 | **建議 1**：開新題目時前一題自動暫停（內容保留）。設 2 以上在 VM 題多時記憶體可能不夠 |
| 無連線自動暫停（分鐘） | 沒連終端機超過這個時間就暫停環境 |
| 全系統實例總數上限 | 預先建立實例時檢查，避免超過儲存空間能容納的數量 |
| 預設語言 | 繁體中文 / English / 依瀏覽器語言；作答者和管理者都可自行切換 |
| 編號格式 | 綁定編號時檢查的正規表示式 |

## 作答者端看到什麼

1. 登入（預發帳號）→ 第一次登入輸入編號兩次綁定
2. 首頁：目前開放的題組（測驗進行中時直接進測驗）
3. 題組頁：題目列表、各題分數、剩餘時間
4. 題目頁：左邊題目敘述，右邊終端機；按鈕「檢查作答」「重置環境」「重新連線」；終端機可彈出成獨立視窗
5. 第一次開題會建立環境（LXC 約 10~30 秒，VM 約 1 分鐘）；之後再開只需啟動

作答者環境的帳號是 `user`（可 sudo），沒有網路。

## 用於技術面試

同一套流程也可以給應徵者做實機排錯題（介面用的是中性的「作答者／編號」，不會出現「學生」字樣）：

1. **建立帳號並直接綁定**：「帳號」→「匯入 CSV」，例如
   ```
   username,password,participant_code,note
   cand01,,C2026001,王小明 後端工程師
   cand02,,C2026002,李小華 SRE
   ```
   密碼留空會隨機產生；有填 `participant_code` 就直接綁定，應徵者登入後不用再輸入編號。
   編號要符合「系統設定」的編號格式（預設英數 4~20 字）
2. **建立一個測驗題組**：開放時間設成面試時段（或整天），放入要測驗的題目
   - 每題「限時」例如 20 分鐘、「次數」1 次
   - 「作答者可看到每個檢查項目是否通過」看需求：關閉＝只看到總分，不會提示哪裡還沒修好
   - 需要的話開啟「禁止在終端機貼上」
3. **面試當天**：把帳號密碼給應徵者（線上面試也可以，只要能連到網站）
4. **事後檢視**：後台「作答者頁」可以看到
   - **終端機紀錄**：重播應徵者的整個操作過程，配合輸入列表跳到關鍵指令（看解題思路、有沒有亂試）
   - **檢查紀錄**：每次按檢查的時間與各項目結果
   - 活動紀錄：開題、連線時間與 IP
5. 結束後刪除題組的實例；帳號可刪除或留存紀錄

面試題通常人數少，一般的小主機（例如 16GB 記憶體）就夠用。
